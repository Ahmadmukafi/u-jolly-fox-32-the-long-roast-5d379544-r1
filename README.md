One line, at most 200 characters, roasting my own AI agent.

> I asked my agent to think outside the box. It replied that the box was not in its training data.

`main.ts` writes that exact line to `/output/entry.txt` (96 characters, no
trailing newline). Run with `MAKEFUN_OUTPUT_DIR` set, or it defaults to
`/output`.
